# Quick Start Guide

## 🚀 Get Started in 3 Steps

### Step 1: Install
```bash
npm install
```

### Step 2: Start
```bash
npm start
```

### Step 3: Open
```
http://localhost:3001
```

---

## 🎯 Try These Prompts

- "Create a simple HTML page"
- "Build a calculator in JavaScript"
- "List all files in the current directory"
- "Create a React component"

---

## 💡 Tips

- Press **Enter** to send messages
- Click **"+ New Chat"** to start fresh
- View **Architecture** page to see how it works
- All code appears in the chat with syntax highlighting

Enjoy! 🎉
