System Architecture

AI Agent Flow Architecture

User Input

User sends a request through the frontend interface

Frontend (React/HTML)

Captures input and sends to Express backend via REST API

Backend (Express.js)

Manages sessions, routes requests to AI agent

AI Agent (Groq LLM)

Processes request, decides if tools are needed

Tool Execution

Executes terminal commands if needed

Final Response

AI generates final answer and sends back to user
